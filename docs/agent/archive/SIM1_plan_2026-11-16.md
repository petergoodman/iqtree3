## 5. Pipeline

`sim/pipeline.py`, steps `simulate`, `fit`, `metrics`, `pilot`; paths, binary and threads as arguments, one
replicate per invocation, so it runs unchanged on a cluster.
- **Truths:** `.qmat` at 17 digits for NQ.bird, Q.bird@π*, LG@π*, and the dial f(λ) = S + λA (NQ.bird's
  symmetric and antisymmetric flux, C(λ) = 0.0577 λ). π* committed at 17 digits with provenance; a test
  recomputes it.
- **simulate:** each gene's (length, shape, rate ρ) drawn with replacement from the scaffold table; m =
  Σ ρ_k n_k / Σ n_k; AliSim on T·ρ_k per gene, `-te` tree T·m and `-q` rates ρ_k/m at 17 digits, which
  IQ-TREE's site-weighted renormalization leaves unchanged to rounding (asserted through
  `normalize_part_rates`); one AliSim call per gene (`--simulation-thresh 0`, `-nt 1`, its own directory
  and `-pre`); seeds from `numpy.random.SeedSequence(base, replicate, gene)` in [1, 2³¹ − 1025], recorded
  and checked against AliSim's report; names checked against the tree's leaves; identical sequences
  counted; concatenation and charsets for unequal lengths in tree leaf order; the `-q` file with true
  shapes and rates; a manifest with SHA-256; refuses an existing directory or a stale `.ckp.gz`; asserts a
  rooted tree without a stem. Run directories `~/iqtree3-runs/sim1/<YYYYmmddTHHMMSSZ>-<commit>-<step>/`.
- **fit:** NQC Level 1 (decisions 024, 043): `-q`, `--model-joint NQC+F{π*}`, `-te` T·m, `-blfix`,
  `-keep-ident` (needed under `-te`; honoured under `-q`, reviewer), default domain; options for `-p`
  Level 2, relaxed settings and `GTR20+F{π*}`.
- **metrics:** Ĉ; per-rate log error (RMS, maximum, twofold counts); net-flux error; held-out lnL of fitted
  against true Q on a held-out replicate of 10 genes (`--show-lh` under `-q`, a 3-decimal total, enough for
  differences); ending rule, evaluations, wall and CPU time, the export diagnostic's share.
- **Asserted checks:** the same seed gives byte-identical files; byte-identical when AliSim sees 2 CPUs
  (`taskset`, confirmed by `-vvv`'s seed list) instead of 12; the wiring check, once per truth: IQ-TREE's
  lnL of the true Q (`--show-lh`, `-q`, true shapes and rates, `-keep-ident`) against the oracle's
  `LinkedObjective` built from the exact trees AliSim used (T·ρ_k, partition rate 1), within 1e-8 × |lnL|,
  with |lnL| ≥ 5e4 asserted so that the 3-decimal print is within the line.
