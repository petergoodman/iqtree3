## S3a: single alignment complete

What IQ-TREE does today, for comparison: NONREV prints nothing about its matrix at any verbosity
(`ModelMarkov::writeInfo` prints nothing for a 20-state non-reversible model,
`model/modelmarkov.cpp:368-376`), and nothing about any model on the `+I+G` path at default
verbosity. All new output below lives in NQC's code, apart from one call.

### C++, `model/modelnonrevfixedeq.{h,cpp}` and one call in `main/phyloanalysis.cpp`

1. **One fit record, printed once.** `checkFit` keeps its re-score, bounds and residuals, then:
   - checks `state_freq` bitwise against the parsed target and stops with `outError` on a
     mismatch, the decomposition guard's rule applied after every fit (a write between fits that
     no decomposition sees is caught);
   - under `-v` prints the three record lines in today's wording (scores; bounds; residuals) in
     place of today's `writeInfo(cout)`;
   - after them, when the re-scored lnL is below the start, prints the fall with `outWarning`:
     in the log at every verbosity, on screen except under `-quiet`.
   - The `writeInfo` override is removed. NQC then prints nothing from IQ-TREE's own call sites,
     as NONREV: the `-v` round loop (today's duplicate), the default print at the end of a fit,
     the linked representative's default print, and the kernels' numerical-failure dumps. The
     summary replaces the default prints.
   - `checkFit` runs only outside parallel regions, because unlinked partitions are refused; a
     comment records that.
2. **End-of-run summary (Q1).** Static `ModelNonrevFixedEq::reportRun(IQTree&, ostream&)` prints
   one block per NQC model:
   - target as given with its sum, target normalized from `state_freq` at 17 digits, references,
     domain;
   - fits, the accepted fit's three scores, bounds, residuals, likelihood evaluations.

   It is called once, at the top of `reportPhyloAnalysis`, after its master-only check and
   before its `OUT_IQTREE` early return. That function runs once per analysis, after `--runs`
   has restored the best run. The first draft's site, in `runTreeReconstruction`, would have
   printed once per bootstrap replicate. This is decision 010's "after the final model
   optimization" site, which S4 extends with the export files. It does nothing without an NQC
   model.
3. **Checkpoint keys** (decision 003).
   - Added: `start_score` and `optimizer_score` (17 digits, beside `accepted_score`),
     `accepted_fit`, `bounds`, `residuals` (the seven diagnostics, 17 digits) and `evaluations`
     (`targetFunk` calls, for S3c). `target` is now written from `state_freq`.
   - Restore brings back the coordinates, the three scores and `accepted_fit`. A score missing
     from an older checkpoint becomes NaN and prints as unknown.
   - Restore recomputes bounds and residuals from the rebuilt Q, because they are derived. Today
     the `+I+G` restore of the best start brings back its coordinates but leaves the last start's
     bounds, residuals, start and optimizer scores (found by the survey).
   - `fits` and `evaluations` are counters: restore keeps the larger of current and saved, so
     the `+I+G` restore no longer winds them back, and a resumed run continues them.
4. **Refusals** (decision 008; the list itself is `CODE_PLAN.md` 2.2).
   - **ModelFinder in any form.** Refuse when `Params::dating_mf` is set.
     - `runModelFinder` sets it before it builds any candidate (`main/phylotesting.cpp:1389`).
       That is ahead of the fast tree and the tests; MixtureFinder also reaches it.
     - No NQC model is built before ModelFinder runs (verified by review).
     - It covers `-m MFP`, an omitted `-m` with `-mset NQC+F<name>` (unrefused today), and a
       partition in a partition file that has no model. ModelFinder itself is not edited.
     - A comment says why a flag named for dating is the run-time signal.
     - IQ-TREE's library build copies `Params`, so it is not covered; NQC is not offered there.
   - **Unlinked partitioned use (Q3).** Refuse when `partition_file` is set and `link_model` is
     not. The check comes after the AliSim check, which also sets `partition_file`, so AliSim
     keeps its own message.
   - **`-fs` and HMM.** Both are already refused (`site_freq_file`; `+T`, which `-hmmster`
     requires); S3a adds their tests.
5. `+R4` needs nothing. `RateFree` holds given values fixed. Free values go through its EM, which
   reaches the model only through `setTree` and the base transition matrices.

## S3b: linked training

### C++

1. **`model/linkedmodelhooks.h`** (new, header only, listed in `model/CMakeLists.txt`). An
   abstract `LinkedModelHooks` with three calls:
   - `startLinkedFit(const vector<ModelSubst*> &linked)`;
   - `linkedDerivative(Optimization &objective, double x[], double dfx[])`;
   - `endLinkedFit(const vector<ModelSubst*> &linked, double optimizer_lnl)`.

   A separate header avoids an include cycle: `modelmixture.cpp` includes NQC's header, and
   `partitionmodel.h` pulls in the super tree.
2. **`model/partitionmodel.{h,cpp}`** (decision 005).
   - **`derivativeFunk` override**, declared at the orphan comment in `partitionmodel.h`. It
     delegates when `dynamic_cast<LinkedModelHooks*>(model)` succeeds, else calls
     `Optimization::derivativeFunk`. RTTI is on, and the cast only ever sees a `linked_models`
     entry. `minimizeMultiDimen` runs on PartitionModel only in `optimizeLinkedModel`, so every
     other model meets the unchanged base routine.
   - **`optimizeLinkedModel`**, when the hooks are present:
     - builds the list of partition models with the linked name, in `part_order` (the order in
       which `targetFunk` sums);
     - calls `startLinkedFit` after the `ndim == 0` return and before `minimizeMultiDimen`;
     - keeps the optimizer's score before line 824 overwrites it;
     - calls `endLinkedFit` after the `if (changed)` block, which is before the checkpoint save
       and before the round's `ASSERT`.

     About 15 lines; legacy models take no new branch.
   - **The end call is kept** rather than having the class report only at its report and export
     (`CODE_PLAN.md` section 4's open question). Without it the class cannot learn that a linked
     fit ended, or the optimizer's score. Decision 009's post-fit check and S3-1's "partitions
     included" could not then be met.
3. **NQC** inherits `ModelProtein` first, then `LinkedModelHooks`.
   - **Shared derivative loop.** `scaledDerivative(Optimization &objective, …)` serves both the
     single-model `derivativeFunk` and `linkedDerivative`. It keeps the start-score capture and
     the `-vv` first-gradient print.
   - **`startLinkedFit`** requires every object to be NQC and to equal this one in:
     - target and `state_freq`, bitwise;
     - references, domain (bitwise), chart and version, derivative policy;
     - accepted coordinates, bitwise (state consistency, synthesis 7.3).

     Otherwise it stops with `outError` naming the difference, then sets the start flag. It runs
     at every linked fit, so the first refusal comes after round 1's per-partition nuisance
     updates and before the shared matrix moves. A refusal before those updates would need a
     second call in the PartitionModel constructor; the updates compute nothing wrong (each
     partition uses its own target), so the extra shared edit is not worth it.
   - **`endLinkedFit`** re-scores without counting an evaluation:
     - it sums each linked object's partition lnL directly, in list order, which is bitwise the
       same sum as `targetFunk`'s;
     - a failed build is warned about and its last valid state is scored, as `checkFit` does;
     - re-scoring through `targetFunk` would have recorded K × 1e30 at a failed point;
     - it records the fit in every linked object, each computing its own bounds and residuals
       and checking its `state_freq`;
     - the representative prints the `-v` record and any fall, once, before the round's
       `ASSERT`.
   - **Refusals.** The refusal of `--model-joint` and `--link-model` is removed. The `+H`
     refusal also reads the partition's own model string (`aln->model_name`), because a charset
     written as `NQC+F{…}+H4` never reaches `params.model_name`.
   - **Thread safety.** The `VB_DEBUG` "proposal rejected" print becomes `#pragma omp
     critical`, the idiom at `partitionmodel.cpp:911-915`. It now runs inside `targetFunk`'s
     parallel loop.
   - **`reportRun`** gains one block per linked NQC model, with the partition count.
4. **Thread safety** (constraint 7). Per object, `targetFunk` touches only its own coordinate
   arrays, Q, ν, `rates[]` and eigen arrays. `fixedeq::build` is pure. The base decomposition
   already runs in this loop for NONREV. The hooks run outside the parallel region, and there is
   no static mutable state.
5. **Not changed.** Parameter counting already counts the linked matrix once. No step option is
   added, since decision 007 adds one only for a step study, and S3 has none.
6. **Known and left alone:**
   - a linked NQC run prints QMaker's citation, because the test matches "NONREV" (S4's item);
   - `--link-alpha` is neither refused nor tested;
   - after a tree search IQ-TREE checkpoints no final model, so `--undo` restores pre-final
     state. That holds for every model; NQC's restart tests use `-te`;
   - a reviewer reports, unverified, that resuming an `-S` tree search with `+I+G` may restore
     stale top-level keys, for every model. It is outside S3's paths and noted for PLAN.md.

### Data and oracle

- **`nqc/twopart.py`** (kept, seeds recorded).
  - One seeded rooted 12-taxon tree. Partition A is simulated by the frozen binary's AliSim from
    NQ.pfam's jump chain at the turtle target; partition B from the same chain at the target
    cubed. 600 sites each, with a two-charset NEXUS file.
  - It asserts that no taxon is missing and no two sequences are identical, since `-p` removes
    identical sequences. `-p`'s partition trees then equal the shared tree.
  - It reuses `nqc/toy.py`'s tree and AliSim helpers with taxon, site and seed arguments. Their
    defaults keep the toy data byte-identical, since its SHA-256 is checked.
- **Oracle.** A linked objective sums per-partition `Objective`s, each with its sites, input tree
  text, rate model and partition rate. The rate is folded into the categories, and
  `normalizePartRate`'s operations are repeated in order for `-q`.
- **Driver.**
  - `Runner` takes a thread count; today it appends `-T 1` last, which wins.
  - Runs can be staged with binary files, for the copied checkpoints.
  - Linked fit runs use `-cptime 0 --all-checkpoint`, and every numbered checkpoint is read. A
    linked checkpoint is otherwise dumped at most once a minute, so per-fit checks would see
    nothing.
